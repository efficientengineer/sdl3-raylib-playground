# TILES — the field, Sega style (D18)

Owner's decision (2026-09-19), final after a day of 2.5D, painted block-outs, angled painted screens and
painted top-down maps: **"Sega style, top down, using tile sheets, with walking based on a grid. No more
screen navmesh."** This file is the contract between the engine, the art pipeline and the map authors.
`FIELD.md` (3D) and the painted-screen work are parked: the code stays, nothing new is built on them.

## The look and the numbers

- Phantasy Star IV field: top-down oblique tiles, ground from straight above, objects showing roof and
  south face, hard tile edges, no perspective, no scaling, no blending.
- **Tile = 32x32 px.** Internal view **640x360** (20 x 11.25 tiles; PS4 showed 20 x 14), nearest upscale,
  camera snapped to whole pixels. Walkers are **32x48** (the existing 4x4 walk sheet, rows S W E N), drawn
  with their feet on the tile and their head overlapping the tile above.
- **Grid walking.** Four directions. A step is exactly one tile, animated smoothly (~0.16 s a tile walking,
  ~0.10 s running); input is read at the end of each step, so holding a direction glides tile to tile.
  Diagonal input resolves to the most recent axis. Facing can change without moving (tap). Blocked tile =
  turn to face it, no step. Party members follow in a snake, one tile behind each other, PS4 style.
  Interact acts on the tile faced. Step counts drive random encounters later.

## Tilesets — `story/field/tilesets/<set>/`

- `atlas.png` — a grid of 32x32 tiles, 16 columns, generated by the tool from cut sheets. Index 0 is
  empty/transparent.
- `tiles.md` — one `## <name>` per tile or stamp: `- index: n` (or `- index: n WxH` for a multi-tile
  **stamp**, row-major from its top-left tile), `- layer: ground|object|over`, `- solid: yes|no|<rows>`
  (for a stamp: which of its tiles block, as rows of `#`/`.`), `- desc:` the one-line artist description the
  art pipeline uses. Houses, trees, wells, carts, fences are **stamps** built from tiles; the top rows of a
  tall stamp (roof ridge, tree crown) are `layer: over` so a walker passes behind them.
- **Edges without an autotile explosion**: each terrain that borders grass (dirt, paving, water) has three
  fringe tiles — `edge` (straight, facing north), `corner_out`, `corner_in` — which the engine rotates and
  overlays where that terrain meets another. Three tiles per terrain, not forty-seven.

## Maps — `story/field/tmaps/<map>.tmap`

Plain text, agents and humans edit it by hand.

```
## meta
name: halm
tileset: valley
size: 48 36
spawn: 24 20 S
music: hope
## legend            # one char → tile or stamp name from tiles.md
. grass
, dirt
# paving
~ water
H house_a           # a stamp: the char marks its TOP-LEFT tile; the rest of its footprint is written as '+'
## ground            # size rows, one char per tile (ground layer only)
## objects           # size rows, '.' = nothing; stamps by top-left char, '+' for the rest of the footprint
## triggers          # x y w h kind arg — kinds: exit <map> <x> <y> <facing> | door <map> <x> <y> <facing>
                     #   | message <text-id> | npc <walker> <facing> <text-id> [wander r] | zone <table> | trap <id>
```

Collision comes from the tiles (`solid`), plus NPCs. Doors are triggers on the tile in front of a door
tile. Examine text and NPC lines stay in `story/field/text.md` by id (interact press, "!" above the player
when the faced tile has something). The map design rules from `FIELD.md` still hold inside the grid: towns
grow round a reason, lanes bend and pinch (in tile steps), nothing in rows, ragged edges, paths 3 tiles
wide, one landmark; grids and symmetry are for the ancients.

## Art — ChatGPT tile sheets through the template pipeline

`./story_prompt.py tileset <set>` reads `tiles.md`, lays every tile and stamp out on template sheets (flat
magenta, white-bordered numbered slots, each slot an exact multiple of the tile: **4x, so a tile is a
128-px slot and a 4x3 house is 512x384**), writes the prompt with the locked map style blocks, and `ingest`
cuts the return, downsamples 4:1 to 32 px (nearest after a 4x4 mode filter so fat pixels survive), keys
magenta on `object`/`over` tiles, and packs `atlas.png`. Ground tiles are asked for seamless. A set is a
few sheets: ground+fringes, buildings, nature, furniture. Until a sheet exists the engine draws a
procedural placeholder for that tile, so maps are walkable before art.
