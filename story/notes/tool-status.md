## 1. The tray's status set is now one set

A package's status was decided three times — `packages.py`, the generated
`story/packages/README.md`, and ArtTray's Swift enum — and the three had drifted. The app had no
`stale` at all, so a package whose `look` line had changed read `done` in the GUI and `stale` in the
README: the fingerprinting exists precisely so the owner does not redo work, and the GUI was hiding
its answer.

Now: **`storytool/packages.py` decides, everybody else reads.**

```
pkg_status(dir, meta)            ->  (word, why)      word ∈ STATUS_WORDS, why never empty for
                                                      `stale` / `blocked`
stamp_status(dir, meta)          ->  writes status, status_why, status_label into package.json
                                     (every `packages` run; again in `ingest` the moment it cuts)
write_status_json()              ->  tools/arttray/statuses.json — the word list as data
story/packages/README.md         ->  read_status(dir): prints the stamped word verbatim
tools/arttray (ArtTray.swift)    ->  PackageMeta.status / .statusWhy: shows the stamped word verbatim
```

The five words, and nothing else: `to generate` · `blocked (needs …)` · `stale — <reason>` · `done`
· `frozen`. `exists` is gone (it is `done` with its note kept); `image waiting` and `N/M cut` are
reasons under `to generate`, not statuses. The one thing the app still computes is a live **image
waiting** badge from the file dates, because a `returned.png` dropped in a second ago cannot be in a
`package.json` written this morning — it is drawn as a badge over the stamped word, never instead of
it. `stale` is red in the queue and carries its reason; it is never counted as done.

Drift cannot come back silently: `tools/arttray/run.sh --selftest` asserts the Swift `StatusWord`
enum against `tools/arttray/statuses.json` (generated by `packages`). Renaming a word in Python
fails the Swift selftest until the enum follows. Documented in `storytool/README.md`, *"Package
status: one source, two readers"*.
